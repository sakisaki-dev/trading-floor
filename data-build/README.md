# data-build

The scripts that built `data/` from the Retro Bowl Vault site (a fan stats hub for one Retro Bowl save). They were
written to live in that repository's `sandbox/` folder and use paths relative to it, so they don't run from here.
They're kept for provenance: every number in `data/` can be traced to one of them.

How to rebuild the data, and what each file holds: [docs/DATA.md](../docs/DATA.md).
